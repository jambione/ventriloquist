# Ventriloquist

Ventriloquist lets you speak into an iPhone and see the words appear, live, in a desktop app on a Mac or a Windows PC, ready to copy and paste into a terminal. Transcription runs on the phone (Apple SpeechAnalyzer, iOS 26+), so audio never leaves it. Text travels over Bluetooth LE, end-to-end encrypted after a one-time 6-digit pairing, and the desktop also appends every utterance to a daily Markdown log. It is a personal tool, built from source.

## Architecture

```
iPhone app (SwiftUI)                         Desktop app (Tauri v2 + Rust)
 DictationEngine -> VQPhoneCore (PhoneEngine)  Web UI <- vq-host-core (session, store, logger)
 VQProtocol (Swift)  <--- BLE GATT --->        vq-protocol (Rust) + BLE central (btleplug)
 iPhone = GATT peripheral                      desktop = GATT central
```

The wire format and encryption are specified in [protocol/README.md](protocol/README.md). The full design is in [SPEC.md](SPEC.md); decisions made during the build are in [docs/SPEC_QUESTIONS.md](docs/SPEC_QUESTIONS.md).

## Repository layout

- `protocol/`: Rust crate `vq-protocol`, the wire spec and shared test vectors
- `desktop/core/`: Rust crate `vq-host-core` (sessions, transcript store, logger, transports)
- `desktop/app/`: the Tauri desktop app (Vite + TypeScript frontend)
- `ios/VQProtocol/`: Swift package (`VQProtocol`, `VQPhoneCore`, and the `PhoneSim` fake phone)
- `ios/App/`: the iOS app; the Xcode project is generated by XcodeGen
- `tests/e2e/`: end-to-end test (desktop host over TCP against PhoneSim)
- `docs/`: manual test checklist and recorded spec decisions
- `scripts/verify.sh`: runs every automated gate
- `.github/workflows/desktop.yml`: CI for the desktop app

## Prerequisites

- Rust (rustup, stable) and `cargo install tauri-cli --version '^2'`
- Node 20 and npm
- `brew install xcodegen`
- Xcode with the iOS 26+ SDK, and an Apple ID added under Xcode > Settings > Accounts
- For Windows builds: the Rust MSVC toolchain and WebView2

## Install the iOS app on an iPhone

```sh
cd ios/App && xcodegen && open Ventriloquist.xcodeproj
```

1. In Xcode, sign in under Settings > Accounts, select your iPhone as the run destination and press Run.
2. On the iPhone, turn on Developer Mode (Settings > Privacy & Security > Developer Mode) and restart when asked.
3. Trust the developer profile under Settings > General > VPN & Device Management.
4. Apps signed with a free Apple account expire after 7 days. Run from Xcode again to renew.

## Build and run the macOS app

```sh
cd desktop/app && npm ci && cargo tauri build
open target/release/bundle/macos/Ventriloquist.app
```

Always launch the bundle with `open` (or from Finder). Never run the raw binary from a terminal: macOS blames the terminal for Bluetooth use and aborts the app. Only one instance runs; a second launch focuses the first window.

## Windows

Build on a Windows PC with the same commands (`cd desktop/app`, `npm ci`, `cargo tauri build`), or download a build from GitHub Actions artifacts or Releases (workflow: `.github/workflows/desktop.yml`). Pushing a tag `vX.Y.Z` creates a release. Builds are unsigned, so expect SmartScreen (Windows) and Gatekeeper (macOS) warnings. On macOS, a downloaded app needs:

```sh
xattr -dr com.apple.quarantine Ventriloquist.app
```

## First use

1. Open the phone app and keep it in the foreground: it only advertises while on screen.
2. Open the desktop app. Tap the header on the phone to open the host picker.
3. Choose your Mac (or PC). The desktop shows a 6-digit code; enter it on the phone.
4. Tap the mic to start dictating and tap it again to stop. Text appears on the desktop as you speak. After stopping you can edit on the phone and send a correction.

## Logs

Every finished utterance is appended to `~/Documents/Ventriloquist/YYYY-MM-DD.md`. The folder can be changed in the desktop Settings.

## Testing

- `scripts/verify.sh` runs all automated gates (protocol vectors, desktop core, E2E, clean builds, frontend). Name a gate to run only that one, for example `scripts/verify.sh gate4_ios`.
- `tests/e2e/run.sh` runs the end-to-end test alone.
- [docs/MANUAL_TEST.md](docs/MANUAL_TEST.md) is the on-device checklist.

## Troubleshooting

- The Mac app is stuck on "Connecting…": bring the phone app to the foreground, or quit and reopen the Mac app.
- The iPhone app stopped launching after about a week: the free-account signing expired; reinstall from Xcode.
